# @searsuite/sear-assembly-doc

Composes rich-document plugins for nodes, layout, inline styles, commands, and observations.

Embedded Sheet editing policies use `SheetEmbeddedEditorPlugin` and receive immutable document data only. They transform normalized input, inline styles or commits and observe semantic document changes. Their contract exposes neither Core nor presentation services; drawing and cell geometry are selected independently by the adapter.

[API reference](https://searsuite.com/docs/ref/#sear-assembly-doc)
